# Draco Tattoo – Privacy Policy

Privacy policy for **Draco Tattoo**, a tattoo design app for Android and iOS by Draco Studio.

**Live page:** https://draco-studioz.github.io/tattoo-studio-privacy/

The page is served by GitHub Pages from `index.html` on `main`, in English and Vietnamese. The app opens it from Settings → Privacy policy, and the store listings link to it, so keep this URL stable (don't rename the repo).

When the app's data handling changes, update the page and its effective date before that version ships.
